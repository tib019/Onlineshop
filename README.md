Ein statischer Frontend-Onlineshop für **Vintage Mystery Boxen** – hochwertige Secondhand-Mode für Privatkunden und Großhandel. Das Projekt demonstriert grundlegende Web-Entwicklungsfähigkeiten mit reinem HTML, CSS und JavaScript ohne externe Frameworks.

---

## Projektübersicht

| Eigenschaft | Details |
|---|---|
| **Typ** | Statische Website / Frontend-Projekt |
| **Technologien** | HTML5, CSS3, Vanilla JavaScript |
| **Zielgruppe** | Privatkunden & Großhandel |
| **Thema** | Vintage Secondhand-Mode Mystery Boxes |

---

## Features

- Responsive Design für Desktop und Mobile
- Produktübersicht mit verschiedenen Box-Kategorien
- Kontaktbereich und Impressum
- Reines Vanilla JavaScript – keine externen Abhängigkeiten
- Schnelle Ladezeiten durch minimalen Overhead

---

## Projektstruktur

```
Onlineshop/
 Main.html # Hauptseite mit Shop, Über Uns und Kontakt
 Impressum.html # Impressum-Seite
 styles.css # Globale Styles und Layout
 script.js # Interaktivität und Warenkorb-Logik
```

---

## ️ Installation & Nutzung

Da es sich um eine rein statische Website handelt, ist keine Installation erforderlich.

```bash
# Repository klonen
git clone https://github.com/tib019/Onlineshop.git

# Main.html im Browser öffnen
open Onlineshop/Main.html
```

Alternativ kann die Seite mit einem lokalen Entwicklungsserver (z.B. VS Code Live Server) geöffnet werden.

---

## Vorschau

Das Projekt zeigt einen vollständigen Onlineshop-Flow:

1. **Hero-Bereich** – Ansprechende Einführung mit Call-to-Action
2. **Shop-Bereich** – Produktkarten mit verschiedenen Box-Typen
3. **Über Uns** – Unternehmensvorstellung
4. **Kontakt** – Kontaktformular
5. **Impressum** – Rechtliche Informationen
