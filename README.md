# Vintage Mystery Boxen - Onlineshop

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/CSS)
[![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

Statischer Frontend-Onlineshop für Vintage Mystery Boxen - hochwertige Secondhand-Mode für Privatkunden und Großhandel. Das Projekt demonstriert grundlegende Web-Entwicklung mit reinem HTML, CSS und JavaScript, ohne externe Frameworks.

---

## Features

- Responsive Design für Desktop und Mobile
- Produktübersicht mit verschiedenen Box-Kategorien (Privat und Großhandel)
- Hero-Bereich mit Call-to-Action
- Unternehmensvorstellung und Kontaktbereich
- Impressum-Seite
- Vanilla JavaScript ohne externe Abhängigkeiten
- Schnelle Ladezeiten durch minimalen Overhead

---

## Tech Stack

| Kategorie | Technologie |
|-----------|-------------|
| Markup | HTML5 |
| Styling | CSS3 |
| Interaktivität | Vanilla JavaScript |

## Projektstruktur

```
Onlineshop/
  Main.html        # Hauptseite mit Shop, Uber Uns und Kontakt
  Impressum.html   # Impressum-Seite
  styles.css       # Globale Styles und Layout
  script.js        # Interaktivitat und Warenkorb-Logik
  tests/           # Playwright-Tests
```

---

## Installation & Verwendung

Da es sich um eine rein statische Website handelt, ist keine Installation erforderlich.

```bash
git clone https://github.com/tib019/Onlineshop.git
```

`Main.html` direkt im Browser öffnen oder einen lokalen Entwicklungsserver verwenden (z.B. VS Code Live Server).

---

## Tests

Das Projekt enthält Playwright-Tests für End-to-End-Tests:

```bash
npm install
npx playwright test
```
