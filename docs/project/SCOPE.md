# Projektscope — Onlineshop

## Problem
Demonstrationsprojekt für einen einfachen Onlineshop mit Produktanzeige, Warenkorb und Bestellprozess als Lernprojekt für Web-Development-Grundlagen.

## Lösung
Statischer Onlineshop mit Vanilla HTML/CSS/JavaScript, demonstriert grundlegende E-Commerce-UI-Konzepte.

## In Scope
- Produktlisting (`Main.html`)
- Produktdetailansicht
- Warenkorb (JavaScript-basiert)
- Impressum (`Impressum.html`)
- Jest Unit-Tests
- Playwright E2E-Tests

## Out of Scope
- Echte Zahlungsabwicklung
- Backend/Datenbank
- Nutzer-Login und Bestellhistorie
- SEO-Optimierung

## Technologie-Stack
| Schicht | Technologie |
|---------|-------------|
| Markup | HTML |
| Styling | CSS |
| Logik | Vanilla JavaScript |
| Tests (Unit) | Jest |
| Tests (E2E) | Playwright |
